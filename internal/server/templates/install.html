Install tok

The command-line client your agents use to read tokens from this server.

macOS and Linux

Installs tok to ~/.local/bin and the Claude Code skill to ~/.claude/skills/tok, then logs in:

curl -fsSL {{.URL}}/install.sh | sh
tok login {{.URL}}

Change the locations with TOK_BIN_DIR and TOK_SKILL_DIR, for example curl -fsSL {{.URL}}/install.sh | TOK_SKILL_DIR=~/.codex/skills/tok sh.
