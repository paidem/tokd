Install tok

macOS / Linux

Installs tok to ~/.local/bin and the Claude Code skill to ~/.claude/skills/tok:

curl -fsSL {{.URL}}/install.sh | sh
tok login {{.URL}}

Override with TOK_BIN_DIR / TOK_SKILL_DIR, e.g. curl -fsSL {{.URL}}/install.sh | TOK_SKILL_DIR=~/.codex/skills/tok sh.
